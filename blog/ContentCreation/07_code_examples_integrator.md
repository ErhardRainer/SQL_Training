# 07 - Code Examples Integrator

## Aufgabe
Arbeite die Codebeispiele gezielt in den Artikel ein.

## Modusregel
Dieser Schritt entfaellt bei `pipeline_mode: article_only`.

## Regeln
1. Beispiele nur dort platzieren, wo sie argumentativ tragen.
2. Nicht jeden Dialekt mit gleich viel Code darstellen.
3. Keine unverbundenen Code-Anhaenge.
4. Codebloecke muessen das jeweilige Kapitel stuetzen.
5. Kurze Einordnung vor und nach jedem wichtigen Beispiel.
6. Dialekt-spezifische Vorpruefungen und Sicherheitsmuster werden in ihrer natuerlichen Form integriert, nicht auf ein SQL-Server-Muster zurechtgebogen.
7. Wenn eine merkfaehige Hauptvisualisierung vorbereitet wurde, wird sie an der passenden Stelle in den Artikel integriert.
8. Wenn der Artikel geaendert wird, setze `workflow_phase` auf `07_code_examples_integrator`.

## Ziel
Der Leser soll erkennen, wie die Theorie mit echten SQL-Beispielen, natuerlichen Dialektmustern und den tragenden Visualisierungen zusammenhaengt.
